Known causes

Before you write in

SymptomCauseFix
Login fails after sign-in, blank or 403 page Your Gmail is not in the consent screen's Test users list Google Cloud Console → OAuth consent screen → add the account
Tokens die after exactly 7 days The consent screen is still in Testing Publish the app, or re-run python auth.py weekly
Missing OAuth client file client_secret.json not placed Move it to ~/.config/opencode/google/ and chmod 600
this does not look like a Desktop app client A Web application client was created Recreate the OAuth client as Desktop app
redirect_uri_mismatch Same cause as above Recreate as Desktop app
Not authorized for X A scope was not ticked at consent Delete token.json, re-run auth.py, tick all scopes
Refused: … not inside the app folder Target points at a normal Drive folder Uploads go to opencode/ only. Move files afterwards in Drive
Server missing in OpenCode OpenCode not restarted, or config not patched Restart OpenCode; check the mcp block for opencode-google
invalid_grant after re-auth An old token is still present Delete token.json, then python auth.py
Publish app blocked, demands Branding fields Branding page incomplete Fill app name, support email, developer email. Homepage and logo are optional
Never send secrets. Do not paste token.json, client_secret.json, your Aztra key, or the contents of an email thread into a support email or a public issue. A refresh token is equivalent to your password for the scopes granted. If one leaks, revoke it immediately at myaccount.google.com/permissions.

Scope of support

What I can help with

In scope:

  • Installer failures on macOS, Linux, or Termux
  • OAuth errors in auth.py and setup_check.py
  • Tool behaviour that contradicts SOP.md
  • Bugs in the MCP server itself

Out of scope:

  • Your Google Cloud project's billing or quota
  • Google's verification and CASA assessment process
  • Debugging your own OpenCode configuration or model provider
  • Recovering a credential you have lost or leaked
opencode-suite

Single-purpose installers for OpenCode. Local MCP servers, narrow scopes, secrets that never leave your machine.
